# E-Commerce Fitness Website

A front-end e-commerce web application focused on fitness products and services. This repository contains the user interface for browsing fitness gear, managing a shopping cart, and handling user login. 

## Features

Based on the project structure, the website includes the following core pages:
*   **Landing Page (`index.html`):** The main entry point for the fitness store.
*   **Product Store (`Website.html`):** The primary interface for browsing fitness items.
*   **Shopping Cart (`CartPage.html`):** A page allowing users to review their selected products.
*   **User Portal (`LoginPage.html`):** An authentication screen for returning customers.

## Technologies Used

*   **HTML:** Used for the structural layout of the web pages[cite: 1].
*   **CSS:** Used for styling and design across multiple stylesheets (`style.css`, `styles.css`, `styleee.css`)[cite: 1].
